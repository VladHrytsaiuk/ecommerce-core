# Огляд інтеграцій (3rd-Party Services)

Цей документ містить огляд зовнішніх сервісів, які інтегровані в бекенд AquaWheel. Усі модулі інтеграцій знаходяться у директорії `internal/integration/`.

---

## 📦 1. Нова Пошта (`novaposhta`)

Інтеграція дозволяє отримувати списки міст/відділень, розраховувати вартість доставки та автоматично генерувати ТТН (товарно-транспортні накладні).

- **Налаштування `.env`**:
  ```bash
  NOVA_POSHTA_API_KEY="ваш_ключ_з_кабінету_нової_пошти"
  ```
- **Як це працює**: 
  - Усі запити виконуються через JSON API Нової Пошти.
  - Довідники (міста, відділення) зазвичай кешуються або зберігаються в нашу БД через окремі cron-задачі або під час первинного наповнення (див. модуль `shipment`), щоб не "смикати" API Нової Пошти при кожному відкритті чекауту.
  - Генерація ТТН відбувається під час оформлення замовлення, коли статус замовлення змінюється на "Відправлено" або адміністратором вручну.

---

## 📮 2. Укрпошта (`ukrposhta`)

Аналогічно до Нової Пошти, використовується для доставки та створення ТТН. Укрпошта має більш складну авторизацію.

- **Налаштування `.env`**:
  ```bash
  UKRPOSHTA_BEARER="Bearer_токен_авторизації"
  UKRPOSHTA_ECOM_TOKEN="eCom_токен_для_оплат_і_доставки"
  ```
- **Як це працює**:
  - Має REST API для отримання індексів, адрес та відділень.
  - Використовує eCom токен для генерації стікерів (наліпок) для відправки.

## 💳 3. LiqPay (`liqpay`)

Платіжний шлюз для прийому онлайн-оплат (картки Visa/Mastercard, Apple Pay, Google Pay).

- **Налаштування `.env`**:
  ```bash
  LIQPAY_PUBLIC_KEY="public_key_з_кабінету"
  LIQPAY_PRIVATE_KEY="private_key_з_кабінету"
  # URL вашого бекенду, куди LiqPay буде слати HTTP POST запити зі статусом оплат
  LIQPAY_SERVER_URL="https://api.aquawheel.com/api/payment/webhook/liqpay" 
  ```
- **Як це працює (Оплата)**:
  - Бекенд генерує об'єкт `data` (JSON з сумою, валютою `UAH`, та `order_id`) та кодує його в base64.
  - Бекенд генерує `signature` за формулою: `base64_encode(sha1(private_key + data + private_key))`.
  - Ці два параметри відправляються на фронтенд, який ініціалізує віджет оплати.
- **Як це працює (Webhooks/Колбеки)**:
  - Webhook ендпоінт **публічний**, тобто не захищений JWT токеном, оскільки запит робить сервер LiqPay.
  - 🛡️ **Безпека**: Щоб хакер не міг надіслати підроблений запит "оплачено", бекенд **обов'язково** перевіряє `signature`, який прийшов від LiqPay. Ми беремо `data` з запиту, додаємо наш `private_key` (який знаємо тільки ми та LiqPay), хешуємо і порівнюємо з отриманим `signature`. Якщо збігається — змінюємо статус замовлення на "Оплачено".

## 📱 4. Vodafone OBM SMS (`sms`)

Використовується для відправки OTP кодів (верифікація телефону) та системних сповіщень.

- **Коротка суть**: Працює через REST API v3 від Vodafone. 
- **Деталі**: Ця інтеграція має дуже багато нюансів (авторизація, вкладена структура JSON, формати номерів), тому вона винесена в окремий великий гайд.
- 🔗 **Детальна документація**: Див. [phone_verification_obm_sms.md](phone_verification_obm_sms.md).
